# Recursos do jogo

Esta pasta vai guardar recursos originais do projeto, organizados por tipo:

- `characters/`: modelos, texturas e animações de personagens.
- `stages/`: cenários e respetivas texturas.
- `audio/`: música e efeitos sonoros.
- `ui/`: imagens e elementos do menu.

Use nomes simples, documente a origem de cada recurso e confirme que tem autorização para o incluir. Não adicione ficheiros grandes ou formatos incompatíveis com PSP sem testar primeiro.

Neste momento, a pasta contém apenas esta documentação; ainda não há modelos, cenários ou áudio finais.
