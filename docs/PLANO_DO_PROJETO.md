# Plano inicial do projeto

## 1. Antes de programar

- [ ] Confirmar o objetivo exato do projeto e a plataforma de destino.
- [ ] Confirmar se o trabalho é para PSP, Android, PC ou outra plataforma.
- [ ] Escolher a ferramenta de desenvolvimento compatível com o destino.
- [ ] Definir os requisitos mínimos e os recursos necessários.

## 2. Organização

- [ ] Criar a estrutura de pastas adequada à ferramenta escolhida.
- [ ] Adicionar um protótipo mínimo que possa ser aberto e testado.
- [ ] Documentar como executar o projeto.
- [ ] Manter os ficheiros-fonte no GitHub.

## 3. Testes e entrega

- [ ] Testar num ambiente compatível com a plataforma escolhida.
- [ ] Corrigir erros antes de gerar a versão final.
- [ ] Documentar os passos de compilação.
- [ ] Só marcar uma versão como concluída depois de testar o artefacto gerado.

## 4. Cuidados com os recursos

Usar apenas recursos próprios, de domínio público ou com licença que permita a utilização pretendida. Não incluir credenciais, tokens, palavras-passe ou ficheiros pessoais no repositório.

## Estado

Este plano é provisório. A estrutura técnica e os passos de compilação serão definidos depois de confirmar a plataforma de destino.
