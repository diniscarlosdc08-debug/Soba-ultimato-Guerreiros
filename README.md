# Soba Ultimato Guerreiros

Repositório inicial do projeto **Soba Ultimato Guerreiros**.

## Estado atual

Este repositório está a ser preparado. Ainda não contém o jogo completo nem um ficheiro ISO pronto para instalar ou executar.

## Objetivo

Organizar os ficheiros, a documentação e os recursos necessários para desenvolver o projeto de forma gradual, mantendo o trabalho versionado no GitHub.

## Estrutura prevista

- `docs/` — decisões, instruções e planeamento do projeto.
- `assets/` — imagens, áudio e outros recursos, respeitando as respetivas licenças.
- `src/` — código-fonte, quando a tecnologia do projeto estiver definida.
- `build/` — resultados de compilação; ficheiros grandes e gerados não devem ser enviados sem necessidade.
